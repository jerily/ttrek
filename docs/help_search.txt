Usage: ttrek search [-registry URL]... [-add-pubreg] QUERY

Find packages on registry websites. The default endpoint is
https://ttrek.sh/registry/search?q=QUERY. Search works outside a project.

-registry requires an HTTP(S) API base URL that supports GET BASE/search?q=QUERY.
Explicit directory paths produce an error.
Explicit sources take precedence over the nearest project's saved registry list.
Search skips saved directory entries and uses ttrek.sh when the list has no website.
-add-pubreg appends the public website. A synced checkout has no effect on search.
Across websites, an earlier registry's package takes precedence over later copies.

Queries accept 1–255 ASCII letters, digits, spaces, '.', '_', '+' or '-'.
Matching ignores ASCII case. Quote phrases such as 'web server'.
Results show the package name, optional languages in brackets, and a
tab-separated description when available. No matches prints nothing and succeeds.

The public website ranks exact names, prefixes, name substrings, literal
descriptions and tags, then typo matches. Search requires a network connection.

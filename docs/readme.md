## Using ttrek

- [Install ttrek](install.md): installation, build tools and updating ttrek itself.
- [Use ttrek](usage.md): create projects, find packages, install, preview and update.
- [Registries](registries.md): sync the public catalog and select local or HTTP sources.
- [Scripts](scripts.md): run project and package scripts, or generate standalone builds.
- [Personal-site example](example/readme.md): install a Tcl site and edit its journal and notebook.
- [OpenACS quickstart](openacs/readme.md): install and start a local OpenACS instance.
- [Tk quickstart](tk/readme.md): install Tk and explore its widget demos.

## Developing ttrek

- [Build from source](build.md): dependencies, build settings and CMake commands.
- [Development](development.md): project principles, solver integration and tests.
- [Releases](releases.md): prepare platform binaries, upload them and record checksums.
- [Security](security.md): trust boundaries, protections and current limitations.

Run `ttrek help` to list commands, or `ttrek help COMMAND` for detailed options.

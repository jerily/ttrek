Usage: gen-script [-shell bash|sh] [-static] [-strategy latest|favored|locked] ?package@version_range ...?

Write a standalone build script to stdout. The default shell is bash.
Resolve project dependencies and include their recipes and patches in build order.
With no package arguments, also include the project's build recipe.
Hooks run when the generated script is executed, not during generation.
Generation does not install packages, change project files, or send telemetry.

The script installs into build/install beside the script and needs no ttrek binary.
-static enables the +static USE flag for conditional recipe options.
Static Tcl extensions require registration by an embedding application.

Examples:
    ttrek gen-script > build.sh
    ttrek gen-script -shell sh -static jinja2-tcl > build.sh
    bash build.sh

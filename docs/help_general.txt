Usage: ttrek [-registry SOURCE]... [-add-pubreg] COMMAND [options]

-registry accepts a directory or an HTTP(S) registry API base URL. Repeat it to
search sources in order. Directories contain package/version/ttrek.json and
adjacent .diff patches. The first source containing a package supplies all its
versions and recipes; only an absent package advances to another source.
Source downloads still use recipe URLs. Options also work after init, install,
update, pretend, gen-script, clone or search. init saves the ordered list in ttrek-lock.json;
other commands use it for that invocation. Explicit options replace saved or
default sources. Relative saved paths use the project directory.
-add-pubreg appends the public default after the explicit or saved sources,
regardless of option placement: the synced ~/.local/ttrek-registry when available,
otherwise https://ttrek.sh/registry. init saves this as a portable public entry.
With no explicit or saved sources, ~/.local/ttrek-registry is used after a
successful ttrek sync, otherwise the ttrek.sh website. Normal commands never
create or clone this directory.

Available commands:
    init
    clone
    install
    pretend
    gen-script
    update
    sync
    self-update
    uninstall
    ls
    search
    run
    scripts

Run 'ttrek help COMMAND' for more information on a command.

Running ttrek without a command shows this help. Set TTREK_DEBUG to show
internal commit IDs, reset details and individual file operations.

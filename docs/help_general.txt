Usage: ttrek [-registry DIRECTORY] COMMAND [options]

-registry reads DIRECTORY/package/version/ttrek.json and adjacent .diff patches.
It replaces the registry API for this invocation. Source downloads still use
the URLs in each recipe. It also works after init, install, update, pretend or gen-script.
init saves the directory in ttrek-lock.json; other commands use it for that invocation.
An explicit option overrides the saved registry. Relative saved paths use the project directory.
Otherwise ~/.local/ttrek-registry is used after a successful ttrek sync, before
the ttrek.sh website. Normal commands never create or clone this directory.

Available commands:
    init
    install
    pretend
    gen-script
    update
    sync
    self-update
    uninstall
    ls
    run
    scripts

Run 'ttrek help COMMAND' for more information on a command.

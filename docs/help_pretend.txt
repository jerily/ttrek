Usage: pretend [-registry SOURCE]... [-add-pubreg] [-strategy latest|favored|locked] [-force] ?package@version_range ...?

Resolve the project with the same solver and planner used by install/update.
Read ttrek.json and the optional ttrek-lock.json and ttrek-venv/ttrek-manifest.json,
check installed files, and print the install plan.
Do not write project files, create a venv, run hooks, or install packages.
The default strategy is favored, as for install; use latest to preview update.
-registry appends a local directory or HTTP(S) API URL; repeat to set lookup order.
-add-pubreg appends the public default after explicit or saved sources
(synced local copy, otherwise API) without changing the saved configuration.

Examples:
    ttrek pretend tjson twebserver
    ttrek pretend -strategy latest

The first registry containing a package supplies its versions and recipe.
Only an absent package advances to the next registry; other errors stop lookup.
Explicit sources replace the saved list and defaults for this invocation.
